# Автобусы МПЗ — мини-приложение

Две вкладки: **Карта** (шторка с ближайшей остановкой, временем пешком и на машине, ближайшим автобусом и переключателем «До завода / Обратно», выбор МПЗ Богородский или РЦ Кудиново, планирование даты и времени) и **Расписание** (все рейсы по маршрутам, поиск по остановке).
Шрифты Nunito и Roboto, карта Leaflet + OpenStreetMap лежат в папке `vendor` — внешние сервисы не нужны. Открывайте по HTTPS-ссылке (не из файла): тайлам OpenStreetMap нужен заголовок Referer.

Файлы для загрузки: `index.html`, `app.css`, `app.js`, `config.js`, `data.js` и папка `vendor`.

## Что умеет карта сейчас
- **Переход дороги.** Если рядом (до 130 м) есть остановка с другой стороны дороги, рейсы с неё тоже предлагаются: «Перейдите дорогу на остановку…, ≈3 мин». Если тот же автобус можно взять на другой стороне без лишней поездки по петле, приложение выбирает этот вариант («Лучше перейти дорогу»). Радиус задаёт `CROSS_M` в `app.js`.
- **Только маршрут.** Когда рейс выбран, на карте остаются остановки этого рейса. Кнопка с глазом показывает все остановки.
- **Откуда.** Кнопка «Изменить» рядом с названием остановки открывает выдвижное окно: поиск остановки, «Где я», «Точка на карте» и поиск адреса. Адрес ищется в OpenStreetMap (Nominatim) только по нажатию Enter или кнопки, без подсказок на каждую букву. Точку «вручную» можно перетащить на карте.
- **Расписание.** Сверху фильтр по городам (Ногинск, Электросталь, Электроугли, Лосино-Петровский, Монино, Свердловский), ниже день: сегодня, завтра, будни и воскресенье, суббота, и выбор даты и времени.

## Местоположение (и VPN)
Приложение берёт местоположение только у самого устройства (GPS, Wi-Fi, сотовая сеть) через стандартный запрос браузера/WebView. IP-адрес не используется, поэтому VPN на него не влияет.
Если точка всё же определилась неверно (далеко от района рейсов или точность хуже 1,5 км), приложение предупреждает и предлагает «Указать на карте».
Внутри СБС геолокация работает, только если приложение СБС разрешает WebView доступ к местоположению.
Тему можно принудительно задать в адресе: `index.html?theme=dark` или `?theme=light` (по умолчанию — как в системе).

## Автоматическое построение линий
`python3 build_geometry.py` строит линии каждого рейса одним запросом по всем его остановкам (без разворотов) и пишет их в `routes_geometry.json`; затем `python3 build_data.py raspisanie.xlsx`. Ключи `--rebuild` (перестроить всё) и `--route 478`. Трудные участки правятся точками в `route_via.json`. Подробности — в шапке скрипта.

## Редактор для логиста
`admin.html` — страница для правки рейсов (откройте её рядом с `index.html`, нужен интернет): смена времени и остановок, красный пунктир = нет линии по дороге, кнопка «Построить по дорогам», точки пути, перетаскивание остановок. Кнопка «Скачать data.js» сохраняет результат; этим файлом заменяют `data.js` на сайте. Не запускайте после этого `build_data.py`: он заново возьмёт данные из Excel и затрёт правки.

## Узловые остановки (МПЗ, РЦ)
Остановка со значком ⚓ (файл `stop_hubs.json`) считается узловой: маршрут подъезжает и уезжает с любой стороны, без петель, и не сдвигается вместе с одним рейсом. После отметки нажмите в редакторе «Исправить петли у узловых».

## 1. Как подготовить карту с нуля (администратор)
Откройте `index.html?edit=1` на компьютере.
1. «Найти координаты» — приложение ищет остановки по названиям (сначала в Яндекс-геокодере по `geocoderKey`, если не нашлось — в OpenStreetMap). Около 45 запросов.
2. Проверьте метки на карте, неточные перетащите на место.
3. «Построить линии по дорогам» — для каждой пары соседних остановок запрашивается дорожная линия в OSRM (около 80 запросов, 1–2 минуты). Эти линии потом рисуются без запросов.
4. «Копировать координаты» → вставьте в файл `stops_coords.json`; «Копировать линии» → в `routes_geometry.json` (оба рядом с `build_data.py`).
5. Выполните `python3 build_data.py raspisanie.xlsx` — всё попадёт в `data.js`.
6. Загрузите `index.html`, `app.css`, `app.js`, `config.js`, `data.js` и папку `vendor`. Ключ `geocoderKey` после этого из `config.js` лучше удалить: пользователям он не нужен.

## 2. Обновить расписание
Замените Excel и выполните `python3 build_data.py raspisanie.xlsx` (нужен Python и `pip install openpyxl`).
Скрипт читает блоки «Маршрут N Утро/Вечер (…)», режет их на рейсы по остановке «МПЗ Богородский»
и определяет тип времени по цвету ячейки, как в легенде таблицы:
оранжевый — точное, без заливки — ориентировочное, жёлтый — по требованию, зелёный — для сотрудников РЦ.
Новые остановки: добавьте строку поиска в `stops_queries.json`, затем снова пройдите шаги 1–5 (уже найденные остановки и линии сохранятся).

## 3. Встраивание в СБС
Папка статическая. Загружайте её как веб-приложение (раздел «Веб-приложения» REST API СБС) или откройте по HTTPS-ссылке.
Геолокация работает, только если WebView приложения разрешает доступ к местоположению — проверьте на тестовой версии.

## 4. Подложка карты и условия
По умолчанию — стандартные тайлы OpenStreetMap, смягчённые CSS-фильтром (в тёмной теме инвертируются). Это публичный сервис без гарантий доступности:
правила (operations.osmfoundation.org/policies/tiles) запрещают массовую загрузку, а при большой нагрузке доступ могут ограничить.
Для 600 сотрудников обычная работа укладывается в разумное использование; если карта начнёт блокироваться, в `config.js` укажите `tileUrl`
другого провайдера (CARTO, MapTiler, Stadia и др.) — смотрите его условия и ключи.

Проверка времени без ожидания: `index.html?t=17:30&dow=3` (dow: 0 — вс … 6 — сб).
